# Landscape Generator Parallax v1.0.0

First public release of the reconstructed multilingual landscape generator.

## Web edition (available for public release)

- Generate layered mountains and building skylines in the browser.
- Customize up to 24 layers, including per-layer type, color, amplitude and detail.
- Reproducible random seeds.
- Animated parallax preview with adjustable speed.
- Export a complete PNG and individual transparent PNG layers in a ZIP, including `capa_00_cielo.png`.
- Interface available in Spanish, English, French, German, Portuguese, Italian, Russian, Simplified Chinese, Japanese and Hindi.
- Runs offline from `index.html` with `i18n.js`.

**Online app:** https://raulcamaracarreon.github.io/Landscape-Generator-Parallax/web/

## Desktop edition (release pending)

The Windows/PySide6 edition has passed functional testing. Public redistribution of prebuilt Windows executables is **pending** completion of the Qt/PySide6 LGPLv3 compliance checklist described in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The Windows ZIP is not included among automated public release assets until that review is completed.
